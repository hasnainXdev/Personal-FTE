# 👋 Welcome to Your AI Employee Vault

This is your **Personal AI Employee** knowledge base and control center, powered by **Qwen** as the reasoning engine.

## 📁 Folder Structure

| Folder | Purpose |
|--------|---------|
| `/Inbox` | Raw incoming items (files, notes) |
| `/Needs_Action` | Items requiring AI processing |
| `/Done` | Completed tasks archive |
| `/Plans` | Multi-step task plans |
| `/Pending_Approval` | Actions waiting for human approval |
| `/Approved` | Approved actions ready to execute |
| `/Rejected` | Declined actions |
| `/Logs` | Activity and error logs |
| `/Accounting` | Financial transaction records |
| `/Briefings` | CEO briefings and reports |

## 🧠 AI Brain: Qwen

This system uses **Qwen** as the primary reasoning engine instead of Claude Code. Qwen provides:
- High-level reasoning and planning
- File system understanding
- Multi-step task completion
- Natural language processing

## 🚀 Quick Start

### For Bronze Tier

1. **Drop a file** in `/Inbox` or create action item in `/Needs_Action`
2. **Run Qwen** in this vault directory
3. **Ask Qwen to process** the Needs_Action folder
4. **Review and approve** any pending actions
5. **Check Dashboard.md** for status updates

### Example Commands

```bash
# Navigate to vault
cd bronze/AI_Employee_Vault

# Process pending items
# Use Qwen CLI or API to process
qwen "Check /Needs_Action and process all pending items"

# Update dashboard
qwen "Update Dashboard.md with today's activity"
```
